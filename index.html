La Ley del Orden

Imagínate organizar un festival de música. No puedes hacerlo solo. Necesitas un equipo: uno para el sonido, otro para las luces y otro para la comida.

En software, esos "equipos" son las Funciones. Cada una hace una sola cosa, pero juntas crean el festival.

Definición Técnica

Una función (o subprograma) es un bloque de código independiente y reutilizable, diseñado para realizar una tarea específica. Recibe datos de entrada (parámetros), ejecuta instrucciones (cuerpo) y opcionalmente retorna un resultado, favoreciendo la abstracción y la modularidad del código fuente.

2

La Ley de la Información

¿Cómo guardarías las notas de 100 estudiantes en 5 materias diferentes? Si usas variables simples, necesitarías 500 nombres.

Las Matrices son como un estante organizado por pasillos (filas) y niveles (columnas). Un solo nombre guarda todo.

Definición Técnica

Una matriz (o arreglo bidimensional) es una estructura de datos estática que almacena múltiples elementos del mismo tipo de dato bajo un identificador común. El acceso a cada elemento en la memoria se realiza mediante un sistema de indexación compuesto por dos coordenadas espaciales: el índice de fila y el índice de columna.

Impacto de la Modularización

A medida que tu código crece, las funciones evitan que el esfuerzo se dispare exponencialmente.

Conceptos Clave

  • Ámbito Local: Lo que declaras dentro de una función no existe afuera. Es como la privacidad de tu habitación.
  • Parámetros: Son los nombres que la función usa para referirse a los datos que le envías desde afuera.
  • Variable de Retorno: Es el mensajero que lleva el resultado final de vuelta al programa principal.

Así se ve en PSeInt

Funcion resultado <- CalcularDescuento(precio, tasa)
    Definir resultado Como Real
    resultado <- precio - (precio * tasa / 100)
FinFuncion

Algoritmo Principal
    Escribir CalcularDescuento(1000, 15) // Salida: 850
FinAlgoritmo

La Analogía del Reloj 🕰️

Para recorrer una matriz usamos dos bucles.

El bucle de las **Filas** es como la aguja de las horas: se mueve lento. El bucle de las **Columnas** es como la aguja de los minutos: da una vuelta completa (todas las columnas) antes de que la fila avance un solo paso.

¡Ojo con esto!

En PSeInt, si vas a pasar una matriz a un subproceso para llenarla, DEBES usar Por Referencia. Si no lo haces, los datos que guardes se perderán al terminar la función.

Ejemplos Prácticos

Aprende viendo cómo se resuelven problemas reales. Desde conceptos básicos hasta estructuras complejas.

Nivel Básico

1. Calculadora de Área (Funciones)

El Problema

Necesitamos un programa que calcule el área de un círculo repetidas veces sin tener que escribir la fórmula matemática cada vez.

Explicación Paso a Paso

  • Definición: Creamos la función CalcularArea que recibe la variable radio.
  • Proceso Interno: Declaramos area_calc. Multiplicamos PI (3.14159) por el radio al cuadrado.
  • Retorno: La función devuelve el valor almacenado en area_calc.
  • Programa Principal: Pedimos el radio y llamamos a nuestra función.

Código PSeInt

Funcion area_calc <- CalcularArea(radio)
    Definir area_calc Como Real
    area_calc <- 3.14159 * (radio * radio)
FinFuncion

Algoritmo Principal
    Definir r, resultado Como Real
    Escribir "Ingrese el radio:"
    Leer r
    resultado <- CalcularArea(r)
    Escribir "El área es: ", resultado
FinAlgoritmo

Nivel Intermedio

2. Suma Diagonal (Matrices)

El Problema

Tenemos una matriz 3x3 y necesitamos sumar únicamente los números de su diagonal principal (donde fila == columna).

Explicación Paso a Paso

  • Dimensionar: Matriz[3,3].
  • Doble Bucle: Llenamos la matriz con números usando bucles anidados.
  • La Lógica: Un solo bucle Para i <- 1 Hasta 3 es suficiente para la diagonal principal, ya que accedemos a M[i,i].

Código PSeInt

Algoritmo SumaDiagonal
    Definir M, i, j, suma, cont Como Entero
    Dimension M[3,3]
    cont <- 1; suma <- 0
    
    // Llenado (simplificado)
    Para i<-1 Hasta 3 Hacer
        Para j<-1 Hasta 3 Hacer
            M[i,j] <- cont; cont <- cont+1
        FinPara
    FinPara
    
    // Suma Diagonal
    Para i<-1 Hasta 3 Hacer
        suma <- suma + M[i,i]
    FinPara
    Escribir "Suma: ", suma
FinAlgoritmo

Nivel Avanzado

3. Búsqueda Modular (Matrices + Funciones)

El Problema

Saber si un valor existe dentro de una matriz 4x4, delegando la tarea de búsqueda a una función independiente.

Explicación Paso a Paso

  • Por Referencia: Pasamos la matriz a la función por referencia para ahorrar memoria.
  • Bandera: Usamos retorno <- Falso. Si en el doble bucle M[f,c] == num, cambiamos a Verdadero.
  • Algoritmo Limpio: El código principal solo llama a la función y decide qué mensaje mostrar según el resultado Lógico.

Código PSeInt

Funcion retorno <- ExisteValor(M Por Referencia, num)
    Definir f, c Como Entero
    Definir retorno Como Logico
    retorno <- Falso
    
    Para f<-1 Hasta 4 Hacer
        Para c<-1 Hasta 4 Hacer
            Si M[f,c] = num Entonces
                retorno <- Verdadero
            FinSi
        FinPara
    FinPara
FinFuncion

Algoritmo Principal
    // ... (Asumimos Matriz 'Datos' ya llena) ...
    Si ExisteValor(Datos, 7) Entonces
        Escribir "Encontrado!"
    Sino
        Escribir "No existe."
    FinSi
FinAlgoritmo
